我遇過最心痛的一次，是同學在燒錄系統時選錯了磁碟，把自己隨身碟裡整學期的報告清得一乾二淨。燒錄這件事本身不難，難的是**按下「寫入」那一刻，你選的真的是對的那張卡嗎？** 這篇我們把整個流程走一遍，但重點放在「哪一步會改寫資料、按下去之前要確認什麼」。

## 這篇會學到什麼

- 什麼是系統映像，Raspberry Pi Imager 在做什麼。
- 燒錄 Raspberry Pi OS 到 microSD 卡的步驟。
- 第一次開機後，怎麼確認系統真的裝好了。

## 需要的東西

- 一台能執行 Raspberry Pi Imager 的電腦（Windows、macOS 或 Linux）。
- 讀卡機。
- 一張**備用**的 microSD 卡。**燒錄會清除卡上所有資料**；請不要用 RP5 現在正在用的那張卡，也先備份卡上要留的東西。
- Raspberry Pi 5、電源，以及螢幕、鍵盤、滑鼠（或打算之後用 SSH 遠端）。

> 原文建議至少 8 GB、Class 10 以上的卡；這是原文的建議，本教材沒有另外測試最低需求。

## 先懂幾個名詞

- **映像檔（image）**：一個已經把整套系統打包好的檔案。燒錄就是把它原封不動寫進記憶卡。
- **Raspberry Pi Imager**：官方的燒錄工具，幫你選機型、選系統、選目標卡，再寫入並驗證。
- **燒錄**：把映像寫進卡片。被選中的卡上原本的資料**全部會被覆蓋**。

## 一步一步操作（尚未實測）

### 步驟 1：下載並開啟 Imager

**為什麼**：Imager 會自動抓官方最新的系統，比自己下載映像再找工具寫入更不容易出錯。

到 [Raspberry Pi 官方軟體頁面](https://www.raspberrypi.com/software/)下載 Raspberry Pi Imager，安裝後開啟。

### 步驟 2：選裝置和作業系統

**為什麼**：不同型號、不同版本的系統，適合的套件不一樣。

1. 裝置選 **Raspberry Pi 5**。
2. 作業系統選 64 位元的 Raspberry Pi OS。這門課會用到桌面和 Thonny，所以選**有桌面**的版本。
3. 原文提到三種選擇，差別如下：

| 版本 | 內容 | 適合 |
| --- | --- | --- |
| Full（完整版） | 桌面＋推薦軟體 | 想要什麼都有 |
| With Desktop（桌面版） | 只有桌面 | 本課程一般用途 |
| Lite（精簡版） | 只有文字介面 | 伺服器或不接螢幕的感測節點 |

官方的版本名稱和預設選項可能改變，請以 [Raspberry Pi OS 官方文件](https://www.raspberrypi.com/documentation/computers/os.html)為準。

### 步驟 3：選目標卡——最重要的一步

**為什麼**：選錯就會清掉別的磁碟。

選擇**備用** microSD 卡，**核對容量和裝置名稱**，確定不是你的隨身碟、外接硬碟或系統碟。不確定就先把其他外接裝置拔掉。

### 步驟 4：設定帳號、時區、網路和 SSH

**為什麼**：如果你打算不接螢幕、直接用網路遠端操作，帳號和 SSH 一定要在這裡先設好，不然開機後你會連不進去。

依 Imager 畫面設定：

- 使用者名稱和密碼：**自己建立**，不要使用網路文章裡寫的預設帳密。密碼不要寫進作業或公開教材。
- 時區、鍵盤配置。
- Wi-Fi 名稱和密碼（如果不用網路線）。
- 開啟 SSH（新 05 會用到）。

### 步驟 5：寫入並等待驗證

**為什麼**：Imager 寫完會再讀一遍比對，確定資料沒寫壞。

再確認一次目標卡，按下寫入。等到顯示寫入與驗證完成，才安全退出卡片。

### 步驟 6：第一次開機

**為什麼**：要先斷電再插卡，避免卡片或板子出問題。

1. RP5 斷電狀態下插入 microSD 卡。
2. 接上螢幕、鍵盤、滑鼠（或確認網路線／Wi-Fi 已設定）。
3. 接上電源，等它開機。

### 步驟 7：確認真的裝好了

**為什麼**：「寫入成功」和「系統能用」是兩件事，要分開確認。

開機後用[新 02](./02-%E8%AA%8D%E8%AD%98%E4%BD%A0%E7%9A%84%E5%B0%8F%E9%9B%BB%E8%85%A6%EF%BC%9ARaspberry%20Pi%205%20%E8%88%87%20Raspberry%20Pi%20OS.md)的指令，確認型號、架構和系統版本。下面這些要分別記錄，每一項都是獨立的結果：

- Imager 是否顯示寫入與驗證完成。
- RP5 是否開機進到桌面（或登入畫面）。
- 自己設的帳號能不能登入。
- `head -1 /etc/os-release` 顯示的系統版本。
- 需要的網路、相機是否可以用（之後各篇會再測）。

## 常見問題

| 你看到的情況 | 可能原因 | 怎麼做 |
| --- | --- | --- |
| 開機沒反應 | 卡片沒燒好、沒插好，或電源不穩 | 確認卡片插好、換一條可靠的電源線；必要時重新燒錄 |
| 連不上 Wi-Fi | Wi-Fi 名稱或密碼打錯 | 重新在 Imager 設定，或先改用網路線 |
| 燒錄失敗 | 卡片有問題或下載不完整 | 換一張卡，或重新下載 |
| 開機後 SSH 連不進去 | 燒錄時沒開 SSH，或帳號沒設好 | 回到步驟 4 確認設定 |

### 已經有 Bookworm，可以直接升級成 Trixie 嗎？

Raspberry Pi 官方在 [Trixie 發布文章](https://www.raspberrypi.com/news/trixie-the-new-version-of-raspberry-pi-os/)中建議的方式，是用 Imager 或官方映像**重新燒一張乾淨的 Trixie**，而不是在舊系統上原地升級。本教材的這台 RP5 也沒有做過升級測試。

## 小結

燒錄只有幾個步驟，但「選目標卡」那一步錯了就無法挽回。用備用卡、先備份、按寫入前再看一次。開機後，把「寫入成功」「能開機」「能登入」「版本正確」分開檢查，這才算真的裝好。

**練習**：

1. 解釋為什麼燒錄前一定要辨認目標儲存裝置。
2. 如果 RP5 不接螢幕，為什麼帳號和 SSH 要在 Imager 先設定好？
3. 有桌面的版本和 Lite 版，各適合什麼情境？
