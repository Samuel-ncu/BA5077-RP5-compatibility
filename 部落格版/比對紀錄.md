# 比對紀錄

digithouse.net 原文與 repo `教材/` 逐篇比對。每篇記四件事：

- **A｜原文在目前 Trixie 已失效或改變**：原文的指令、套件或步驟，在目前 Trixie 已經不能用或改了。
- **B｜repo 版新增**：repo 版新增的實測、程式與排錯。
- **C｜原文有、repo 版遺漏**：原文有，但 repo 版沒有寫到。
- **D｜兩邊互相矛盾**：原文和 repo 版說法不一致，或 repo 內部前後不一致。

依新課號順序排列；課號後面括號是原課號。原文全部公開（HTTP 200，不需要登入）。

**全篇通則**：

- repo 教材開頭的「原始文章」連到 PIXNET，不是 digithouse；比對時以 digithouse 課程目錄為準，逐篇對到 repo 課號。digithouse 文章網址的編號和 repo 課號不一致：`lesson-05`、`lesson-06` 各出現兩次，`lesson-21` 出現三次，沒有 `lesson-22`，`lesson-40` 對應 repo 第 44 課。部落格版一律寫 repo 課號。
- 初步比對是逐字比對指令字串，所以會多報「遺漏」（例如 `apt install qiv` 和 `apt install -y qiv` 會被當成不同）。只有人工對讀後的結果才寫入本紀錄。
- 有六篇 repo 教材（第 04、08、10、16、28 課、補充 7）寫了實際的區網 IP。第 03 課說「未將實際區網位址寫入公開教材」，兩者矛盾。部落格版一律不寫 IP。
