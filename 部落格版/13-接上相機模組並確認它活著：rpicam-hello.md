相機是這門課的眼睛。但我看過不少同學一拿到相機就急著寫程式，結果程式報錯，才發現排線插反了，或系統根本沒看到相機。這篇我們把「接上」和「確認」分成兩件事：先依官方說明接好線，再用一行指令問系統「你看得到相機嗎？」。系統看得到，後面的程式才有意義。

## 這篇會學到什麼

- RP5 的相機接頭在哪裡，接線要注意什麼。
- 用 `rpicam-hello --list-cameras` 確認系統偵測到相機。
- 為什麼「列出相機」和「成功拍照」要分開測試。
- 原文的 `libcamera-*` 指令和現在的 `rpicam-*` 是什麼關係。

## 需要的東西

- Raspberry Pi 5 和一個相容的相機模組（本教材的相機，系統顯示為 `imx708_wide`）。
- **和 RP5 接頭相容的排線**：RP5 的相機接頭比舊型號小，舊排線不一定能用。
- 終端機（[新 08](./08-%E7%B5%82%E7%AB%AF%E6%A9%9F%E5%85%A5%E9%96%80%EF%BC%9A%E6%9C%80%E5%B8%B8%E7%94%A8%E7%9A%84%20UNIX%20%E6%8C%87%E4%BB%A4.md)）。

## 先懂幾個名詞

- **感測器**：相機裡把光變成電子訊號的晶片。
- **CSI 接頭**：板子上專門接相機的扁平接頭。RP5 上標示為 `CAM/DISP0` 和 `CAM/DISP1`，可以接相機或顯示裝置。
- **排線**：連接相機和 RP5 的扁平軟線，有方向性。
- **rpicam-apps**：Raspberry Pi 官方的相機指令工具，例如 `rpicam-hello`、`rpicam-jpeg`、`rpicam-vid`。

## 一步一步操作

### 步驟 1：關機、斷電，再接排線（尚未實測）

**為什麼**：通電時插拔排線，可能弄壞相機或板子。

1. 先關機，**拔掉電源**。
2. 對照 [Raspberry Pi 官方相機文件](https://www.raspberrypi.com/documentation/accessories/camera-software.html)，確認排線兩端的接頭、方向和鎖扣。
3. 輕輕掀起接頭的鎖扣，把排線插到底，再壓回鎖扣。**不要硬塞**。
4. 接好後再接上電源開機。

本教材沒有拍攝接線過程；細節請以官方文件為準。

### 步驟 2：問系統「看得到相機嗎？」

**為什麼**：系統看不到相機，任何相機程式都會失敗。先確認這一層，出錯時才知道要查硬體還是查程式。

開機後，在終端機輸入：

```bash
rpicam-hello --list-cameras
```

實際輸出節錄：

```text
Available cameras
-----------------
0 : imx708_wide [4608x2592 10-bit RGGB]
```

怎麼讀：

- `0` 是相機編號。接兩台相機時會有 `0` 和 `1`。
- `imx708_wide` 是感測器型號，`4608x2592` 是它最大的解析度。
- 後面還會列出其他可用的影像模式。你的相機型號不同，名稱也會不同，這不代表連接失敗。

如果**沒有列出任何相機**：關機、斷電，再檢查排線方向、是否插到底、鎖扣是否壓好。

### 步驟 3：讓 Python 取得一張影格

**為什麼**：列得出相機，不等於拍得到畫面。這一步確認程式真的能從相機拿到資料。

用 Picamera2 擷取一張 320 × 240 的影格，實際輸出：

```text
Picamera2 capture: (240, 320, 3) uint8
```

這代表拿到了一張高 240、寬 320、3 個顏色通道的影像。它沒有測試每一種解析度、錄影或桌面預覽。Picamera2 的寫法會在[新 14](./14-%E7%94%A8%20Picamera2%20%E6%8B%8D%E4%B8%80%E5%BC%B5%E7%85%A7%E7%89%87%E4%B8%A6%E5%AD%98%E6%AA%94.md)、[新 15](./15-%E7%9B%B8%E6%A9%9F%E7%95%AB%E9%9D%A2%E8%AE%8A%E6%88%90%E6%95%B8%E5%AD%97%EF%BC%9APicamera2%20%E5%8A%A0%20OpenCV%20%E8%AE%80%E4%B8%80%E5%BC%B5%E5%BD%B1%E6%A0%BC.md) 一步一步教。

### 原文的 libcamera 指令

原文使用 `libcamera-hello`、`libcamera-jpeg -o test.jpg`、`libcamera-vid -t 10000 -o test.h264`，並用 `sudo apt install -y libcamera-apps` 安裝。repo 教材記載，官方相機程式從 Bookworm 起改名為 `rpicam-*`，所以本教材一律用 `rpicam-hello` 這類新名稱。舊名稱在目前 Trixie 上還能不能用，本教材**尚未實測**。

原文也示範了兩台相機用 `--camera 0`、`--camera 1` 指定，這部分本教材**尚未實測**。

## 常見問題

| 你看到的情況 | 可能原因 | 怎麼做 |
| --- | --- | --- |
| `--list-cameras` 沒有列出任何相機 | 排線沒插好、方向相反、鎖扣沒壓，或排線不相容 | 關機斷電後重新檢查；對照官方文件 |
| 列得出相機，但程式拍照失敗 | 另一個程式正在使用相機 | 關掉其他相機程式（預覽、錄影）再試 |
| `rpicam-hello: command not found` | 相機工具沒有安裝 | 尚未實測安裝方式；先確認系統是含桌面的 Raspberry Pi OS |
| 型號和本文不一樣 | 你用的是不同相機 | 正常，不代表連接失敗 |

## 小結

相機要分兩步確認：先用 `rpicam-hello --list-cameras` 確認系統看得到，再用程式確認拿得到影格。接排線前一定要關機斷電，並對照官方文件確認方向。原文的 `libcamera-*` 指令，在本教材改用 `rpicam-*`。

3. 畫出相機、排線、RP5、程式、照片之間的關係。
