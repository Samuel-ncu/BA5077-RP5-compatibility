# BA5077 教材與 Raspberry Pi 5 相容性查核

本專案依原文章標題整理 56 篇教材，對照 Raspberry Pi 5、Raspberry Pi OS Bookworm 64 位元與學生使用 Thonny 的需求，記錄已實測的內容及尚未完成的部分。以下狀態整理自截至 2026-10-29 已公開的文章與測試紀錄；**某個範例已成功執行，不代表該課所有操作、環境安裝及應用情境均已完成驗收**。

## 已完成或已有實測紀錄

以下指列出的**具體工作**已有紀錄；每篇仍可能有待完成項目，請以[逐篇 Thonny 實測狀態](./教材/Thonny逐篇實測狀態.md)及各篇文章為準。

- **教材整理**：已依 56 個原文章標題建立教材，加入背景、練習和後續應用；部分文章附原文差異、程式、輸出、素材下載說明及操作截圖，完整性仍須逐篇核對。圖片包含相機實拍、程式輸出、合成素材與操作截圖，需依各篇標示區分。
- **設備與基礎操作**：已確認 RP5 為 8 GB RAM，使用 64 位元 Bookworm；已測 SSH、VNC 遠端桌面、相機影格、qiv 圖片開啟，以及 nano、vi 的基本編輯儲存。第 1～11 課仍須核對其餘原文操作。
- **Thonny 與 OpenCV**：已在 Thonny 測試建立部分虛擬環境、安裝及執行 OpenCV，並實測部分繪圖、圖像處理、相機拍照與影片範例。不同環境及各課完整操作尚未全數驗證。
- **YOLO 和相機網頁**：已在既有環境透過 Thonny 執行 YOLO 圖片、短影片、相機偵測，以及 Flask 相機到 RP5 本機瀏覽器的 150 影格示範。第 42、43 課另有兩分鐘預覽、Q 鍵停止及相機重開的實測；第 41 課兩分鐘影片由重複影格組成，並非真實動態長影片。
- **TFLite 與 MediaPipe**：已測模型下載、單圖分類，以及新建但繼承系統套件的環境中兩分鐘相機分類、Q 鍵與相機重開；手部及臉部已有單圖或相機無手情境測試，並曾測生成的雙手圖片與像素距離。
- **EAST、OCR、Ollama**：已測 EAST 模型下載、空白圖負例、相機校正照片的文字框與英文逐框辨識；繁體中文有合成圖片測試。Ollama 已透過 Thonny 下載小模型並以本機服務推論，完整新系統安裝仍待測。

## 尚未完成

- **逐篇教材驗收**：56 篇仍需依原文核對學習目標、操作、程式、實際輸出、對應截圖、素材與模型下載步驟、排錯、練習和原文差異。現有部分測試不能直接算作整篇完成；尤其第 1～11 課仍需逐篇核對系統操作，而非因不以 Thonny 為主就視為完成。
- **乾淨環境與安裝**：OpenCV、相機、YOLO、MediaPipe、TFLite、OCR 及 Ollama 的完整安裝流程仍需逐項核對；某些測試使用原有環境或繼承系統套件，並不等於全新系統安裝。學生除基本系統安裝設定外，應能依教材在 Thonny 完成環境、套件及程式操作。
- **相機與影片**：各課尚缺的連續預覽、影像處理、停止與相機重開仍須依個別文章補測；第 41 課須補真實動態長影片、輸出影片讀回與播放，以及處理時間記錄。兩分鐘測試不代表數小時穩定。
- **Flask 相機網頁**：已有 150 影格本機測試，跨裝置、多客戶端、長時間與乾淨環境尚未驗證。
- **MediaPipe 手勢**：真人連續手勢、剪刀石頭布完整辨識及勝負、真人雙手特徵點與距離仍待驗證；像素距離不能直接當作實際長度。
- **OCR 與文字偵測**：已公開紀錄以靜態圖與負例為主；相機即時 EAST／逐框 OCR、繁體中文實際相機情境及不同光線角度仍須依教材驗證。
- **其他原文情境**：例如第 3、4 課其他網路及 Apache 情境、第 6 課 MobaXterm X11 端到端轉發、第 8 課 qiv 安裝過程、第 10 課設定截圖，以及人臉即時偵測、物件追蹤等各篇列出的剩餘情境。
- **備用 microSD 與 Hailo 模組**：尚無備用 microSD 與 Hailo 模組；系統重新寫入／首次啟動及 Hailo 加速實測先列待完成，不在現有系統上宣稱已驗證。AI HAT+ 2 請依當時[官方 AI 文件](https://www.raspberrypi.com/documentation/computers/ai.html)確認系統相容性。

目前沒有足夠依據給出 56 篇「全部完成」的可靠百分比或保證日期；已完成／待完成以每篇列出的具體範圍為準。測試結果可能受網路、儲存空間、軟體版本、相機條件與可用硬體影響。
