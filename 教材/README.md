# 一起用 Raspberry Pi 學習影像與 AI

我們會先認識小電腦，練習連線和寫第一行 Python，再讓它看見圖片與相機畫面。第一次上課，先讀[學習前先讀我](./學習前先讀我.md)；遇到紅字，可以和老師一起看[排錯故事](./程式卡住時怎麼辦.md)。

下面保留原課程的 56 個標題，方便找課。進入 Python 時，我們先在第 12 課練習保存和執行，再到第 14 課準備 OpenCV，最後回第 12 課讀懂圖片資料。相機課則先完成第 07 課，再選可以使用 Picamera2 的環境。

[如何下載程式和圖片](./練習素材/素材下載與使用.md) · [選擇今天的 Python 環境](./Thonny環境與套件安裝.md#選擇今天的學習環境)
