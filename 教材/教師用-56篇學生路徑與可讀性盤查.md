# 56 篇教材的學生學習路徑與可讀性盤查

盤查／編修日期：2026-11-11。這份表是給教師的備課紀錄，學生入口改由[課前學習說明](./學習前先讀我.md)帶領。

## 結論：目前不能保證零基礎學生只照文章就完成全部目標

逐篇檢查了 56 篇的環境前提、第一個練習、連結檔案、程式語法與閱讀順序。主要缺口不是單一套件改版，而是課文把「老師這台機器曾成功」誤放成「學生已準備好」的前提；部分課標題的完整任務也超過已提供的練習。這次不把任何課程改標為完整實機驗收。

本次修正：第 12、14、15、17 課全文改為情境→小步操作→觀察→解釋→下一步，編修前原文另存歷史紀錄；其餘課補具體學習情境，把原有開場狀態移至文末教師備註，並對已有 Trixie 段落提供明確閱讀入口。移除反覆出現的維護模板，保留原始輸出、截圖和素材說明。這是編修，不表示其餘 52 篇已全文完成教科書化。

新增了面向學生的排錯故事和只讀環境觀察程式。共用指南改先說明今天要用哪個工具箱；不再要求學生從多個歷史環境自行拼湊。

另找到會直接阻斷練習的程式問題：第 17、22、23 課下載程式把讀圖位置固定在教師測試的 `/tmp/ba5077-…`。本次同步修改程式與文章，改用程式所在資料夾；學生將指定圖片放在程式旁即可。這項修正尚未在 RP5 重跑，原截圖仍是修正前實驗的證據。

## 這批如何檢查，還沒有檢查什麼

本機靜態檢查涵蓋 56 篇、107 段 Python 程式區塊與 140 份可下載 Python 程式，語法檢查通過；另核對本次變更的 71 份 Markdown 之本機檔案連結與章節入口，未發現缺失。可重複執行 `python tools/check_lessons.py` 檢查 56 篇連結及 Python 語法。這些檢查不能證明套件可安裝、模型可即時下載或相機能運作。

環境觀察小程式另在本機 Windows／Python 3.11.9 執行，確認沒有安裝 OpenCV 或相機模組時仍能列出查詢結果；沒有因此安裝新套件。本輪嘗試 SSH 連線 RP5 的 `10.134.19.166:22` 逾時，未新增 RP5、Thonny GUI 或學生從零跟做的實測紀錄。

## 如何驗收下一輪教科書編修

請找一位沒有相關背景的同學，從自己的 RP5 和空練習資料夾開始。教師只觀察，不先口頭補上課文漏掉的路徑或套件。記錄同學第一次停下來的位置：不知道名詞、找不到檔案、選錯環境、沒有看到預期畫面，或不知道怎麼結束。這些都要回到課文同一步補寫。

每節依序交代「為什麼做、現在做哪一小步、會看見什麼、這代表什麼、卡住時怎麼繼續」，再接一個只改一項的練習。版本與原始證據放在教師備註；正文仍須保留影響操作的版本選擇，不能把尚未可用的流程藏起來。

## 檢查範圍與限制

本次靜態檢查由 `tools/check_lessons.py` 重複執行：確認 56 篇的本機檔案連結與 Python 程式碼語法。這些檢查不會安裝套件、開啟相機，也不等於零基礎學生完成操作。未重新安裝系統；目前沒有新增 RP5 安裝或硬體結果。
