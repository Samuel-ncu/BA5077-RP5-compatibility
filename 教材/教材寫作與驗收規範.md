# BA5077 教材寫作與驗收規範

本規範讓高中生能從一台乾淨安裝的 Raspberry Pi 5 開始，理解每一步目的、檢查結果並自行延伸。GitHub Markdown 是完整教材主庫；不另建網站。主要測試版本為 Raspberry Pi OS Trixie 64 位元，Bookworm 步驟只放在清楚標記的舊版備註。

## 一篇教材的順序

1. **學習目標：**用可觀察的動詞說明學生完成後能做什麼，例如「讀取一張圖片並印出寬、高和色彩通道數」。
2. **背景概念：**先解釋問題、名詞和流程，再說明為什麼要做這項操作。可用生活例子，但要指出比喻的限制。
3. **準備項目：**列明 RP5 型號、作業系統、Python、相機、網路、檔案和套件前提。乾淨系統的依賴要在本課重新建立，不能假設學生完成過別課。
4. **操作步驟：**以編號步驟呈現；每一步包含操作、目的和完成判據。命令與程式碼放在 fenced code block，避免省略學生需要建立的檔案或目錄。
5. **預期結果：**提供代表性輸出及如何解讀；版本或影像內容會改變時，指出哪些值應不同。
6. **常見錯誤：**將錯誤訊息連到可檢查的原因和下一步，不要求學生盲目重灌或刪除環境。
7. **練習與延伸：**先讓學生修改一個變因、比較結果，再提出可以使用官方文件或其他資料驗證的問題。
8. **來源與差異：**連回 DigiHouse／原文與可靠的官方文件，說明本版更改了什麼，以及哪些原始情境尚未測試。

## 版本與環境

每篇需要套件的教材都要寫出已測 OS、架構、Python 與套件版本。Trixie 是主要路徑；Bookworm 有不同依賴時，使用「舊版 Bookworm 備註」小節，不要把兩套命令混在同一個步驟序列中。不要在系統 Python 直接執行 `pip install`，也不要在同一 venv 混裝會提供同一個 `cv2` 模組的 OpenCV 套件。

相機課說明 venv 如何讀取 OS 原生 Picamera2。其他課建立套件環境時，使用新的、空的課程環境；不得要求學生依賴前一課的殘留安裝。保護 OS 原生 Thonny、Picamera2、相機驅動及系統管理的套件。

## 圖片標示與裁切

每個素材都用圖說標示來源與用途：

| 標籤 | 含義 | 例子 |
| --- | --- | --- |
| RP5 實拍 | 相機實際拍到的場景；場景若是螢幕合成圖，需再說明 | 相機拍攝螢幕上顯示的合成棋盤 |
| 合成素材 | 程式或生成工具建立的練習輸入 | 合成形狀、AI 生成物件 |
| 概念示意 | 用來說明概念的流程圖或插圖 | Mermaid 資料流程 |
| 操作截圖 | RP5 上實際操作的 UI 或終端機 | Thonny 選取直譯器和執行輸出 |

操作截圖只保留能重現步驟和核對結果的範圍，移除帳號、IP、桌面通知及不相關視窗。以相對圖片路徑連結，例如 `![Thonny 顯示相機取像結果](./圖檔/thonny2-camera-env-test.png)`，並寫清楚測試日期、OS、Python 和套件版本。完整桌面、私人照片或個人資料不提交。

不要把合成素材說成真實物品，也不要把棋盤偵測或程式輸出圖說成安裝截圖。沒有實際保存或驗證的畫面先列為待補。

## 驗收狀態

每個狀態都要說明範圍：

- **待測：**步驟尚未在指定環境執行。
- **部分通過：**只通過明確列出的單一範例或前置檢查；列出未測情境。
- **通過：**學生從 Trixie 乾淨基線按教材完整操作，輸出、相機／素材與錯誤處理均有證據。
- **未通過：**保留錯誤、版本、重現步驟與修正方向；不可只刪除失敗記錄。

一次 `import cv2` 成功不能代表整篇通過；相機讀到一張影格不能代表錄影、串流或校正成功。每項結果要能追溯到測試日期、OS、Python、套件、素材來源和輸出。

## Markdown 與參考寫作

使用 GitHub 支援的標題、編號清單、表格、程式碼區塊、相對連結及圖片替代文字。發布前檢查每個相對連結和圖片路徑可在 repo 開啟。

- [GitHub Markdown 基本語法](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)：確認 GitHub 支援的排版方式。
- [Raspberry Pi Foundation：Testing your computer's vision](https://projects.raspberrypi.org/en/projects/testing-your-computers-vision)：參照以學生任務、逐步操作、結果觀察與反思題組織活動的寫法；本教材仍需依 BA5077 設備與目標重寫，不直接複製其內容。
- [Raspberry Pi OS 官方文件](https://www.raspberrypi.com/documentation/computers/os.html)：核對系統版本、Python 與虛擬環境。
- [Raspberry Pi 相機軟體文件](https://www.raspberrypi.com/documentation/accessories/camera-software.html)：核對 `rpicam` 與 Picamera2 的官方操作。
