# 學生指南：下載並使用本課的圖片、程式與相機測試素材

## 先分辨圖片是什麼

本教材的圖片來源不完全相同，請看每張圖附近的說明：

| 類型 | 意義 | 學生如何使用 |
| --- | --- | --- |
| AI 生成的測試素材 | [物件圖](./AI生成物件測試.png)和[虛構人物與手](./AI生成臉與手.png)是生成圖，不是真實水果或真人照片 | 可下載，放到測試網頁旁，讓相機拍攝螢幕上的圖 |
| 相機照片的處理結果 | 例如[物件測試圖](../圖檔/objects-board.png)及[人臉手部測試圖](../圖檔/facehand-board.png)，是 RP5 拍攝螢幕上的生成圖，再裁切及校正的結果 | 直接下載給程式讀取，或自行拍攝並重新校正 |
| 程式繪製或處理的圖 | 例如色塊、灰階圖片和偵測框，來自教學程式執行結果 | 可先對照，再在 Thonny 執行程式重新產生 |
| Thonny 操作截圖 | 記錄實際執行時的程式、環境或輸出 | 用來對照介面；它不是相機輸入素材 |
| 流程圖 | 為解釋概念所畫的示意 | 閱讀理解；不能當作操作成功的證據 |

生成素材來源及提示詞見[測試素材說明](./測試素材說明.md)。偵測結果受素材、光線和版本影響，不能把虛構人物測試當作真人準確率。各篇另有下載模型或外部資料時，請依該篇的來源、版本及實測狀態辦理；**下載本儲存庫不保證包含所有模型或安裝好所有套件**。

## 方法一：一次下載全部教材，建議初學者使用

1. 在 RP5 開啟 Chromium，前往[本課 GitHub 公開儲存庫](https://github.com/Samuel-ncu/BA5077-RP5-compatibility)。
2. 在儲存庫首頁點綠色 **Code**，選 **Download ZIP**。等下載完成後，開啟下載資料夾；檔名通常是 `BA5077-RP5-compatibility-main.zip`，實際名稱以瀏覽器顯示為準。
3. 使用檔案管理員或壓縮檔管理工具解壓縮 ZIP，記住解壓後的資料夾。它是教材檔案快照，**不是安裝程式**；下載或解壓不會安裝 Python 套件，也不會自動更新。
4. 在解壓後找到 `教材/範例程式`、`教材/圖檔` 與 `教材/練習素材`。保留原資料夾內容，另建一個自己的練習資料夾，把該課所需程式和輸入素材複製進去；在 Thonny 開啟練習資料夾中的程式。
5. 依[Thonny 環境與套件指南](../Thonny環境與套件安裝.md)準備相容的 Python 環境，確認右下角解譯器；再依該篇操作。程式可能會產生或覆蓋同名結果檔，執行前先檢查練習資料夾。

GitHub 官方的[下載檔案說明](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-files-from-github)介紹 ZIP 與單檔下載。請勿直接雙擊不明安裝程式；本課的 `.py` 請先用 Thonny 開啟，檢查內容並依教材執行。

## 方法二：只下載單一程式或圖片

在文章中點選需要的檔案連結，進入 GitHub 檔案頁。Python 文字檔可使用頁面右上角的下載原始檔按鈕；圖片可在檔案頁使用下載按鈕或開啟原圖後另存。儲存時核對檔名與副檔名，避免把 GitHub 的網頁存成 `.py` 或 `.png`。可參考 GitHub 的[原始檔檢視說明](https://docs.github.com/en/repositories/working-with-files/using-files/viewing-and-understanding-files)。

下載後，在 RP5 的檔案管理員把所需檔案放進**同一個練習資料夾**，在 Thonny 選 **File → Open**，選取該資料夾裡的 `.py`，檢查環境後按綠色執行鈕。不同程式指定的檔名不同，請逐課檢查。

將[第 17 課程式](../範例程式/第17課-讀取實拍灰階.py)和[物件測試圖](../圖檔/objects-board.png)複製到同一個新練習資料夾，圖片檔名要保持 `objects-board.png`。在 Thonny 開啟程式並執行；成功時 Shell 印出灰階影像尺寸，並在練習資料夾寫入 `lesson17-camera-gray.png`。本次實測見[第 17 課](../第%2017%20課｜使用%20OpenCV%20讀取灰階圖檔.md)。

### 範例：第 22 課偵測圖中的人臉

將[第 22 課程式](../範例程式/第22課-相機人臉偵測.py)和[校正後的生成素材照片](../圖檔/facehand-board.png)放在同一練習資料夾，圖片檔名保持 `facehand-board.png`。程式另外需要 Haar XML 模型；它使用的系統路徑和準備方式見[第 22 課](../第%2022%20課｜使用%20OpenCV%20進行臉部檢測.md)。用 Thonny 開啟並執行，檢查 Shell 輸出與產生的結果圖。

### 範例：第 25～27 課追蹤與背景減法

下載並解壓完整教材後，建立一個新的練習資料夾。第 25 課先把[合成追蹤程式](../範例程式/第25課.py)放入該資料夾，不需額外圖片。第 26、27 課則分別複製[第 26 課影片差分程式](../範例程式/第26課-影片影格差分.py)、[第 27 課影片 MOG 程式](../範例程式/第27課-影片MOG.py)，以及[相機短影片](./lesson16-camera.avi)；影片名稱須保持 `lesson16-camera.avi`，並與所要執行的程式放在同一練習資料夾。

此影片由 RP5 相機拍攝螢幕上的動畫，之後經裁切與校正；兩課處理的是**已保存的影片**，不需要把相機接上才能重現。依[擴充環境步驟](../Thonny環境與套件安裝.md#第-2527-課在-thonny-建立-opencv-擴充環境)準備套件，用 Thonny 開啟並執行程式；結果 PNG 由程式建立，執行前先檢查同名檔案。圖像和影片不需要另外「安裝」。

素材與程式先前是直接複製到 RP5 測試；這裡的 GitHub ZIP 下載與解壓步驟尚未於本次在 RP5 的瀏覽器逐步重測。

## 讓 RP5 相機拍攝測試畫面

要自行拍攝時，將[測試頁](./RP5相機測試.html)、[AI 生成物件圖](./AI生成物件測試.png)與[AI 生成臉與手](./AI生成臉與手.png)下載到**顯示螢幕的電腦上同一個資料夾**。在該電腦用瀏覽器開啟本機 HTML，選擇畫面，讓 RP5 相機對準它；顯示這個 HTML 不需要安裝 Python 套件。照片由 RP5 上的 Thonny 相機程式拍攝，參考[第 18 課](../第%2018%20課｜使用%20Picamera2%20拍攝照片並保存至本地.md)。素材切換、相機位置和裁切座標會影響結果，不能沿用他人的座標而不檢查。

原始相機照片可能包含螢幕周圍或個人資料，對外分享前應先檢查；本儲存庫提供的是已裁切素材及教材結果，並非所有當時的原始相機照片。
