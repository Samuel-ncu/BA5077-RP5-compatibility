## 學習目標

了解如何在 RP5 終端機查詢系統、工具與網路狀態。讀取資訊的命令通常可以先練習；涉及寫入、覆蓋、移動或刪除檔案的命令，應先確認目標。

## 本次實測的查詢

```bash
uname -m
python3 --version
command -v apt
```

本機實際輸出：

```text
aarch64
Python 3.11.2
/usr/bin/apt
```

`uname -m` 查詢架構；`python3 --version` 顯示 Python 版本；`command -v apt` 查找程式位置。若 `command -v` 沒有輸出，代表目前搜尋路徑沒有找到該名稱。
