# 第一次和 Raspberry Pi 一起學習

你可以把 Raspberry Pi 想成一台小電腦，把相機想成它的眼睛。這門課要做的事，是一步一步教這台電腦取得畫面、處理畫面，再嘗試理解畫面裡有什麼。你不需要先熟悉 Linux、虛擬環境或人工智慧；遇到新名詞時，我們會先把它放回正在做的事情中理解。

## 從哪一課開始？

先讀第 01、02 課，認識這門課和手上的小電腦，再讀第 03、04 課理解連線。如果老師已經準備好系統，你可以沿用它，不需要因為讀到第 05 課就重新寫卡。第 05 課的寫入會清除所選卡片，實作前要和老師一起核對備用卡與要保留的資料。

接著，我們練習用第 10 課的方法看見 RP5 桌面。電腦上開的 Thonny 與 RP5 桌面裡開的 Thonny，是兩台不同電腦上的程式；相機接在 RP5 上時，Python 程式也要在 RP5 上執行。

進入 Python 時，順序稍作調整：**第 12 課先練習輸入、保存和執行一行程式，再到第 14 課安裝 OpenCV，之後回第 12 課完成圖片陣列練習。** 第 13 課需要相機，先完成第 07 課的接線與確認，再和第 15、18 課一起學習取像及拍照。

## 為什麼要選擇 Python 環境？

想像每個專題都有一個工具箱：一般繪圖需要 OpenCV，相機需要 Picamera2，人工智慧範例還會需要模型和其他工具。如果工具箱不同，明明昨天用過的工具，今天的程式也可能找不到。

Thonny 右下角顯示的 Python 路徑，就像「今天拿的是哪個工具箱」。教材中的 `/home/pi/…` 是老師當時的路徑；你的帳號不一定叫 `pi`，不要照抄老師的帳號和資料夾。請依課文建立自己的環境，並在右下角選擇它。

先做[第 14 課](./第%2014%20課｜在%20Raspberry%20Pi%205%20安裝%20OpenCV.md)的繪圖練習。需要相機時，再讀[相機環境的準備](./Thonny環境與套件安裝.md#既有-trixie同時使用-picamera2-與-opencv-擴充功能2026-11-10)。一般繪圖環境不會自動帶入系統相機工具，這是工具箱不同，不表示相機壞了。

## 一份程式，先放進一個自己的資料夾

我們以讀取照片為例。程式若寫著 `cv2.imread('photo.jpg')`，它就要找到這個名字的檔案；把照片放在別處，或存成 `photo.jpg.jpg`，都可能讀不到。

在 RP5 的檔案管理員開啟 Home，建立一個自己的課程資料夾，再為每次練習建立小資料夾。把該次程式、圖片與模型放在課文指定的位置。第一次下載可參考[教材與素材下載](./練習素材/素材下載與使用.md)。下載完整教材後，仍要先閱讀本課說明，才決定要開哪一個範例。

先保存程式，再按綠色 Run。畫面上方是你寫的程式，下方 Shell 是程式的回應。課文中的「實際輸出」可以用來比較，但拍攝內容、速度與辨識分數可能不同；先比較資料的意義，不必追求每個數字一模一樣。

## 讀到不同日期的範例時

本教材保留了兩套系統的學習紀錄：較早的 Bookworm／Python 3.11，以及後來的 Trixie／Python 3.13。它們像不同版次的課本實驗，不能把其中的安裝清單任意拼在一起。如果你使用 Trixie，就先閱讀課文標示的 Trixie 路線；沒有這條路線的進階課程，需要老師先準備環境。

目前仍有課程只能在老師已準備的環境練習，例如舊版 MediaPipe 與部分 YOLO 相機範例。這些課程還不能算作「拿到新系統就能獨立完成」。各課會說明可練習的範圍；缺少安裝路線時，請停在環境確認，老師應先協助，不必讓你一直猜套件版本。

## 遇到紅字時，我們一起找原因

紅字通常會指出程式停在哪裡。你先不用懂整段英文，也不要急著全部重裝。我們只做三件事：找最後一行、確認出錯的步驟、看看是不是拿錯工具箱。

接著讀[程式卡住時，我們怎麼找原因](./程式卡住時怎麼辦.md)。它用課堂上真的遇過的例子，帶你判讀套件找不到、版本不合、圖片讀不到與相機忙碌。把完整訊息和你選的 Python 路徑留下來，老師才能和你從同一個位置繼續。

## 怎樣知道自己學會了？

每做完一個小練習，試著說出：「我給了什麼資料？程式做了什麼？我看到了什麼？」例如，把彩色照片變成灰階後，能指出顏色消失了，但物體輪廓還在，就比只說「程式沒有紅字」更接近理解。

課文中的圖片會標示為操作畫面、相機照片、生成素材或程式結果。老師的實驗紀錄供你比較，也保留當時的限制；它不是你一定要複製出相同數字的標準答案。
