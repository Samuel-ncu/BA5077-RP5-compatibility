## 學生重做基線

在 RP5 開啟終端機，逐行執行。每一項輸出都描述不同問題：系統版本、處理器架構、Python、磁碟空間、Thonny 路徑與套件版本、相機可見性，以及系統 Python 是否已有 OpenCV。若 dpkg-query 沒有回報 Thonny 套件版本，請在 Thonny 的 Help → About 記錄畫面版本。

```bash
cat /etc/os-release
uname -m
python3 --version
df -h /
command -v thonny || true
dpkg-query -W thonny 2>/dev/null || true
rpicam-hello --list-cameras
python3 -c 'import cv2; print(cv2.__version__)'
```

主要基準應顯示 Trixie、`aarch64` 與 Python 3.13.x。最後一行在乾淨基線上預期顯示 `ModuleNotFoundError`；這是後續 venv 安裝前的對照，不需對系統 Python 執行 `pip install`。`rpicam-hello --list-cameras` 顯示可用相機，但不等於已測試拍照或校正。

### OpenCV 測試證據

在全新虛擬環境安裝 `opencv-python==4.12.0.88` 後，已確認 Python 3.13 能匯入 `cv2`、建立合成影像、繪圖並編碼／解碼影像；另確認相機可回傳 640 × 480 影格。這些結果只驗證套件、基本陣列操作及單張相機擷取，不代表第 1–19 課每個程式、視窗、影片或 AI 模型都已在 Trixie 重跑。

`--system-site-packages` venv 可看到 Picamera2 等 OS 套件，但 `pip check` 可能把 venv 沒有安裝的其他系統套件列為缺項。相機環境要以教材列出的匯入路徑、相機擷取與實際範例驗收；純 OpenCV 隔離環境則可以使用 `pip check`。

## 相機校正狀態

以 10 × 7 方格棋盤尋找 9 × 6 內角點，一張影格可找到 54 個角點只表示該影格足以進入校正資料候選。相機內參必須使用至少 10 張有效影格，且相機與棋盤之間的距離、傾斜角度和畫面位置要有變化。收集程式及參數輸出格式已加入教材；收集完成前，不發布相機矩陣、畸變係數、重投影誤差或校正前後比較結果。

## 圖片與截圖規則

- 操作截圖由 RP5 Wayland 桌面擷取，裁切到步驟及可核對的輸出；遮去帳號、IP、通知及無關桌面內容。
- 每張圖片標示為「RP5 實拍」、「合成練習素材」、「概念示意」或「操作截圖」。相機拍攝螢幕上的合成物件，仍要同時交代「相機實拍」和「畫面內容為合成」。
- 圖說附測試日期、OS、Python 與必要套件版本。尚未保存原始畫面或重現的結果標為待補，不用舊 Bookworm 截圖代表 Trixie。
- 棋盤角點偵測圖是程式結果，不是 Thonny 安裝操作截圖。
